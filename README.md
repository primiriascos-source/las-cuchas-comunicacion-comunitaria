# Las Cuchas tienen razón — Comunicación comunitaria en red

Sitio web académico para presentar un análisis del caso **“Las Cuchas tienen razón”** desde tres ejes: comunidad, movimiento y plataforma.

## Qué incluye
- `index.html`: contenido completo y estructura.
- `styles.css`: diseño responsive inspirado en la paleta del material de clase.
- `script.js`: navegación mínima.
- `assets/investigacion-grupo.pdf`: documento base del grupo.

## Publicarlo rápido con GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube **todo el contenido** de esta carpeta a la raíz del repo.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/ (root)` y guarda.
6. GitHub mostrará la URL pública en unos minutos.
